# Cloud_Auditor
A cloud resource auditor that goes through active resources that were left open and logs them into an sql table and notifies the user which tools have been left open for more than a specified period of time.
This project will currently has AWS EC2 implementation and Azure, working on GCP.
## Purpose
This project's purpose is to reduce unwanted infrastructure costs if an engineer leaves some of these services open from testing and forgets to shut them down.
